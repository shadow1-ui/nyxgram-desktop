Nyxgram Desktop 0.2.1 (Windows x64)

Распакуйте весь архив в НОВУЮ отдельную папку Nyxgram и запустите Nyxgram.exe.
Не помещайте файлы в папку установленного Telegram и не переносите его tdata.
Войдите в аккаунт отдельно. Данные этой версии не должны смешиваться с Telegram.

Это независимый клиент на основе Telegram Desktop 6.1.1. Он не является официальным Telegram.
Версия 0.2.1 добавляет настройки Nyxgram: 16 бесплатных собственных иконок, тему «Nyx ночной», короткую отключаемую заставку, клиентский «Локальный Premium» и до 500 локальных закреплений.
Откройте Настройки → Nyxgram. Правой кнопкой по чату → «Закрепить локально · Nyxgram»; уберите закрепление в том же меню. Закрепления хранятся отдельно по аккаунтам на этом компьютере, идут после серверных и не синхронизируются. Лимиты сервера не меняются.
«Локальный Premium» даёт звезду в собственном профиле, выбор эмодзи и локальный эмодзи-статус. Его можно выключить. Статус виден только Вам, платные эмодзи не дают подписку собеседнику и передаются обычным текстом. Серверные лимиты, бусты, платные реакции и расшифровка не разблокируются. Все наши иконки доступны независимо от него.
Выбранная иконка меняет окно/панель задач и собственный ярлык меню «Пуск». Для ярлыка рабочего стола можно выбрать ICO из папки icons вручную. Сам значок EXE всегда исходный Nyxgram. Windows может кешировать значки.
Удалённые сообщения: включите сохранение в настройках Nyxgram. Полученные обычные сообщения остаются в чате слегка приглушёнными с выбранным значком и цветом. До 5000 копий / 8 МБ на аккаунт, шифрование Windows DPAPI. Копии можно очистить. Самоуничтожающиеся и одноразовые сообщения не сохраняются; ранее удалённые сообщения с сервера не восстанавливаются.
Призрачный режим и остальные дополнительные функции Android ещё не перенесены на Windows. Полного совпадения функций пока нет.
Обновления официального Telegram отключены, чтобы они не заменили Nyxgram.
Подписи Authenticode пока нет; Windows может показать предупреждение. Не отключайте защиту системы.
