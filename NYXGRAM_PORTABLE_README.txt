Nyxgram Desktop 0.3.0 (Windows x64)

Первый запуск: распакуйте ВЕСЬ архив в НОВУЮ отдельную папку Nyxgram и запустите Nyxgram.exe. Не смешивайте файлы с официальным Telegram и не копируйте его tdata. При обновлении уже установленного Nyxgram закройте клиент, замените файлы в ЕГО папке, СОХРАНИВ tdata. Аккаунт удалять не нужно.

Настройки → Nyxgram → категории возможностей.
• Призрачный режим: отдельно отключаются отправка прочтения, онлайна, набора текста/записи медиа. Скрытие номера на этом устройстве, подтверждение звонков.
• Истории: клиент не отправляет запросы просмотра/счётчика при включённой защите. Это экспериментальная функция, не серверный Premium Stealth; ответы, реакции и другие клиенты могут раскрыть просмотр.
• ID и DC в одной строке, нажатие копирует только ID. DC определяется по хранилищу фотографии, не по типу телефонного номера. Имя пользователя открывает меню копирования имени, публичной ссылки и ссылки по ID. Последняя не обходит ограничения доступа; незнакомые профили без access hash могут не открыться. Закладки профилей, выбор папки при запуске.
• Нативный анимированный предпросмотр GIF/стикеров с кнопками «Отправить»/«Отмена», включая inline-результаты. Отмена происходит до очистки ввода.
• Полученные до удаления обычные сообщения сохраняются в чате приглушёнными со значком. Есть история правок, поиск, очистка, срок хранения и PIN с автоблокировкой. DPAPI шифрует файлы для пользователя Windows; PIN защищает интерфейс, не заменяет системное шифрование. Самоуничтожающиеся и одноразовые сообщения не сохраняются. До 5000 удалённых копий и 3000 версий, общий лимит 8 МБ; более старые записи удаляются. С сервера старые удаления не восстанавливаются.
• Локальный Premium по аккаунтам: собственная звезда, локальный эмодзи-статус и локальное отображение эмодзи в исходящих сообщениях после ответа сервера и повторного открытия. Собеседник получает обычный текст вместо платных эмодзи. Никакие серверные лимиты, бусты, платные реакции и расшифровка не разблокируются. Можно выключить.
• До 500 локальных закреплений на аккаунт: контекстное меню чата. Они идут после серверных закреплений, не синхронизируются и не меняют состав папок.
• Облегчённый режим, отдельные отключения анимаций, эмодзи/стикеров, автопроигрывания и автозагрузки. Отключение размытия относится к подготовке фона чата, не всем системным эффектам Windows. Есть переход в нативные настройки загрузки/памяти.
• Оформление с локальным примером и кнопкой применения: скрытие времени GIF/стикеров/кружков, аватаров, дат; пресеты, компактные пузыри, переход к нативному оформлению/шрифту. Геометрия Windows отличается от Android. 16 бесплатных иконок, исправленная ночная тема, отключаемая заставка. Некоторые изменения требуют перезапуска.
• Собственная проверка опубликованных обновлений Nyxgram, скачивание ZIP с проверкой размера/SHA256. Замена файлов вручную после закрытия клиента; официальный Telegram не затрагивается. Черновики GitHub не предлагаются как обновления. Экспорт/импорт настроек Windows по разрешённому списку, без сообщений, PIN и данных входа.

Иконка окна/панели задач и собственного ярлыка «Пуск» меняется сразу; Windows может кешировать значки. Значок EXE — исходный Nyxgram; дополнительные ICO включены в icons.

Это независимый клиент на основе Telegram Desktop 6.1.1, не официальный Telegram. Официальный автообновлятор отключён. Подписи Authenticode пока нет; не отключайте защиту системы.
Сборка и автоматические проверки не заменяют ручную проверку функций на Windows.
